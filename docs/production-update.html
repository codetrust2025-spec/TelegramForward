TelegramForward — Production Update

Server: http://187.127.169.159 · Click Copy on any box, then paste in your SSH terminal.

Step 1 — Connect to VPS (from your PC)

Try root first. If it fails, try ubuntu.

ssh root@187.127.169.159
ssh ubuntu@187.127.169.159

Step 2 — Find project folder (run on VPS)

echo "USER=$(whoami)" && echo "HOME=$HOME" && pm2 list && for d in /opt/telegramforward ~/TelegramForward /root/TelegramForward; do [ -f "$d/server.py" ] && echo "FOUND=$d"; done

Paste the output back to support if FOUND= is missing.

Step 3 — Safe update (run on VPS)

Replace the path if Step 2 showed a different folder.

cd /opt/telegramforward
git pull origin main
bash scripts/production_update.sh

If folder is ~/TelegramForward instead

cd ~/TelegramForward
git pull origin main
bash scripts/production_update.sh

If NOT a git repo yet (first-time migrate)

OLD=/opt/telegramforward
BACKUP=/opt/telegramforward_backup_$(date +%Y%m%d)
cp -a "$OLD" "$BACKUP"
git clone https://github.com/codetrust2025-spec/TelegramForward.git /opt/telegramforward_new
cp -a "$BACKUP/data" /opt/telegramforward_new/ 2>/dev/null || true
cp -a "$BACKUP"/session_*.session* /opt/telegramforward_new/ 2>/dev/null || true
cd /opt/telegramforward_new
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cd dashboard && npm install && npm run build && cd ..
pm2 delete all 2>/dev/null || true
pm2 start ecosystem.production.cjs
pm2 save

After update — browser

  1. Open http://187.127.169.159
  2. Hard refresh: Ctrl + Shift + R
  3. Log in accounts if needed, then Start workers

Useful VPS commands

pm2 logs telegram-backend
pm2 status
curl http://127.0.0.1:8000/health

Rollback (if something breaks)

cd /opt/telegramforward
pm2 stop telegram-backend
cp -a backups/pre_update_YYYYMMDD_HHMMSS/data .
cp -a backups/pre_update_YYYYMMDD_HHMMSS/session_*.session* .
pm2 start ecosystem.production.cjs

Replace pre_update_YYYYMMDD_HHMMSS with your actual backup folder name.
