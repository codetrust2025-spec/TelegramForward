Step 3 — One command update (easiest)

Paste this single line in Hostinger Browser terminal:

curl -fsSL https://raw.githubusercontent.com/codetrust2025-spec/TelegramForward/main/scripts/hostinger_one_shot.sh | bash

Wait 5–15 min for === ALL DONE ===, then hard refresh the browser.

Step 3A — Manual update (if curl fails)

cd /opt/telegramforward
git pull origin main
bash scripts/production_update.sh

Script stops old telegramforward, backs up data, rebuilds UI, starts telegram-backend.

Step 3B — First migrate (old install, no git yet)

Use this if git pull fails with "not a git repository".

OLD=/opt/telegramforward
STAMP=$(date +%Y%m%d)
cp -a "$OLD" "/opt/telegramforward_backup_$STAMP"
git clone https://github.com/codetrust2025-spec/TelegramForward.git /opt/telegramforward_new
mkdir -p /opt/telegramforward_new/data
cp -a "$OLD"/session_*.session* /opt/telegramforward_new/ 2>/dev/null || true
cp -a "$OLD/data"/* /opt/telegramforward_new/data/ 2>/dev/null || true
cp -a "$OLD/groups_list.json" /opt/telegramforward_new/data/ 2>/dev/null || true
cp -a "$OLD/custom_message.txt" /opt/telegramforward_new/data/ 2>/dev/null || true
mv "$OLD" "/opt/telegramforward_old_$STAMP"
mv /opt/telegramforward_new /opt/telegramforward
cd /opt/telegramforward
bash scripts/production_update.sh

Rollback — restore old UI (if update breaks)

pm2 stop telegram-backend 2>/dev/null || true
pm2 delete telegram-backend 2>/dev/null || true
cd /opt
mv telegramforward telegramforward_failed
mv telegramforward_old_YYYYMMDD telegramforward
cd /opt/telegramforward
source venv/bin/activate
pm2 start "venv/bin/uvicorn server:app --host 0.0.0.0 --port 8000" --name telegramforward
pm2 save

Replace telegramforward_old_YYYYMMDD with your backup folder name from Step 3B.

Or restore from update backup:

cd /opt/telegramforward
pm2 stop telegram-backend
cp -a backups/pre_update_YYYYMMDD_HHMMSS/data .
cp -a backups/pre_update_YYYYMMDD_HHMMSS/session_*.session* .
pm2 start ecosystem.production.config.js
